# 缺测计量通道的成对协方差与白化交接

数据为振动计的离线特征读数。每次片段上报包含读数、权重和独立有效位。 数据为本地合成。

- `data/capture.json` 保存采集原始内容。records 是交换记录，tensors 字段分开描述名称、类型、形状和值。整数索引从零开始，未指定闭合的区间均为左闭右开。
- `data/capacity.json` 保存制造端的容量、规模或分片条件。大尺寸是接口需考虑的使用规模。工作区计入新分配的解包、转换、归约、版本暂存及交接缓冲。调用方已有只读输入和已消费的输出不计入工作区，额外物化副本计入。

## 交换约定

数组 `x` 为片段观测、通道，`mask` 同形，`w` 为观测权重。各浮点数在输入中按 float64 读取。协方差采用配对归一化后加权总体口径。共测不足的通道组隔离，不跨组借数据。给每组的白化矩阵应为所交付的正定修正协方差的对称逆平方根。
分组覆盖以最小配对有效量判断，包含对角线。谱范数为欧氏算子范数。单通道中心值按该通道的全部有效正权样本求均值，与同版组白化矩阵交付。部署申请组内所有通道齐全时才有效。所有数值等价判定误差 1e-9，覆盖阈值按大于等于判定。

## 计算模块

`pairwhite` 实现成对加权统计、分组白化发布与部署变换：

- 流式累积：只保留交接分组声明的通道对（含对角线）的充分统计量与每片段的稀疏贡献，状态不随样本数平方增长，也不物化完整特征矩阵；行分块处理，瞬态缓冲低于交接的 1024 行 / 2MB 上限。内容一致的重发不重复计入；更正片段先撤销旧贡献再计入新贡献，新旧有效通道对同步更新；同 id 同 rev 内容冲突时报错。
- 发布：组覆盖（含对角线的最小配对有效量 (sum w)^2/sum(w^2)）按大于等于判定，无共测的通道对没有估计、不以填零冒充验证。覆盖达标后把配对协方差的特征值截断到 1/max_norm^2（谱范数约束下 Frobenius 最近的修正），修正量按 Frobenius 范数考核；两个限制无法同守时该组保留上一版白化与均值，无上一版则标为不可用，其他组继续更新。
- 部署：读数减去与组白化矩阵同版发布的单通道加权均值后变换；组内通道不齐或组不可用时跳过该组，同组不混用不同版本。

重跑更正到部署的过程（应用提交日志、发布、对接交读数变换并输出各配对样本量、各组版本与阻止原因）：

```sh
python -m pairwhite data/capture.json
```
